# Security Policy

If you discover a security vulnerability in SimpleStats, please **do not** open a public issue.

Send an email to [simplestats@laracraft.tech](mailto:simplestats@laracraft.tech) instead, with a description of the issue and, if possible, steps to reproduce it. We will get back to you as soon as possible and keep you updated until the issue is resolved.

## Supported versions

Security fixes are applied to the latest version on the `main` branch. Please keep your self-hosted installation up to date.
